# 自動販売機システム (Java Vending Machine)

Javaのオブジェクト指向設計（カプセル化、単一責任原則、DIの基礎）を学習・実践するためのコンソール型アプリケーションです。

## 🚀 現在の機能（MVP版）
- **商品管理**: `StockManager` による在庫の登録と管理。
- **販売管理**: `SalesManager` によるお金の投入、バリデーション（金額・在庫チェック）、購入処理、お釣りの返却。
- **例外処理**: 意図しない操作（残高不足、在庫切れ、存在しない商品）に対する、標準例外（`IllegalArgumentException`, `IllegalStateException`）を用いたエラーハンドリング。

## 🛠 今後の拡張予定（第2形態）
- **Enumとオーバーロード**: `Money` 列挙型の導入による、型安全な硬貨管理。
- **継承とポリモーフィズム**: 基本の `Item` クラスを拡張した特殊商品（年齢確認が必要な `AlcoholItem`、ランダム要素のある `LuckyItem`）の追加。
- **ビジネスルールの動的判定**: `if` 文を増やすことなく、各オブジェクト自身に振る舞いを決定させる設計へのリファクタリング。

## 💻 実行方法
`Main.java` を実行することで、コンソール上で自販機の初期化から商品の購入、エラーハンドリングまでのシナリオテストが自動で行われます。
